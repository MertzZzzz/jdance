# jdance 0.2.2 — аудиоканалы в Channel Rack и ASIO

Каждый сэмпл на Playlist теперь — канал в Channel Rack, который можно
направить в любой трек микшера. На Windows добавлен ASIO-host для
сторонних драйверов звуковых карт.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.2.2-windows-x64.msi` и запустите; установка поверх
0.2.1 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

## Аудиоканалы

- **Любой сэмпл на Playlist получает канал в Channel Rack**: бросок из
  библиотеки, из файлового менеджера, Draw/Paint сэмплом из Project
  Browser, клип из Sample Editor, записанный дубль.
- **Тот же файл бросили ещё раз** — новый клип попадает в уже
  существующий канал этого сэмпла.
- **Маршрут в микшер задаётся каналом**: поле трека в строке канала или
  Ctrl+L (выделенные каналы → выделенный трек микшера). Громкость и
  баланс канала действуют на все его клипы; в центре баланс не меняет
  уровень.
- Строка аудиоканала показывает форму волны и число клипов. Фильтр
  Channel Rack: All / Instruments / Audio. Контекстное меню: Make unique
  (отдельный канал для выбранных клипов), удаление канала вместе с его
  клипами (с подтверждением), «Remove unused audio».
- Playlist: цвет и имя клипа берутся из канала; в меню клипа — Channel,
  Make unique и Mixer track. Поле маршрута у дорожки убрано.
- Project Browser показывает каналы под каждым сэмплом.
- **Запись** идёт в новый аудиоканал дубля; в окне Recording поле
  «To track»: Master, конкретный трек или «New track».
- **Формат проекта 13.** Проекты 0.2.0/0.2.1 открываются и переводятся
  автоматически: на каждую пару «сэмпл + трек дорожки» создаётся канал с
  прежним маршрутом, звучание не меняется. Сохранённый проект старые
  версии не откроют (резервная копия исходного файла создаётся).

## ASIO (Windows)

- В Audio settings backend **ASIO** стоит первым, если установлен хотя бы
  один ASIO-драйвер. Недоступный драйвер виден в списке с причиной.
- Кнопка панели драйвера; частоты, которые принимает драйвер; размер
  буфера из допустимых драйвером (или значение драйвера с подсказкой
  менять его в панели), с пересчётом в миллисекунды.
- Имена каналов драйвера в выборе пары выходов и входа записи.
- Задержки входа и выхода от драйвера показываются в «Active stream»;
  при записи через ASIO они вычитаются из позиции дубля один раз.
- Сброс драйвера (например, смена буфера в его панели) переоткрывает
  поток с той же конфигурацией; идущая запись при этом останавливается.
  Драйвер, переставший отвечать, останавливает поток с сообщением,
  интерфейс не зависает.
- Опция «Release the ASIO driver while jdance is inactive» (по умолчанию
  выключена): при потере фокуса и остановленном транспорте драйвер
  закрывается и открывается снова при возврате.
- Запись через ASIO берёт вход того же драйвера, что играет.

## Известные ограничения

- **ASIO не проверялся на реальном драйвере и железе**: логика проверена
  тестовым драйвером, сборка и тесты — Windows CI. Поддерживаются только
  64-битные драйверы.
- Выравнивание дубля по задержкам драйвера не измерено петлёй
  выход → вход.
- Остальное — как в 0.2.0 (см. заметки к 0.2.0).
