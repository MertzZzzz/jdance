# jdance 0.2.8 — совместимость с VST3-плагинами

Окна плагинов рисуются правильно на экранах с масштабом, плагины,
которые не открывались или не загружались, открываются, а смена задержки
плагина больше не закрывает его окно и не прерывает звук.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.2.8-windows-x64.msi` и запустите; установка поверх
0.2.7.1 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта не менялся (17). При первом запуске плагины из чёрного
списка проверяются заново: часть из них теперь загружается.

## Окна плагинов (Windows)

- **Масштаб экрана (125 %, 150 %, 200 %).** Плагин, который умеет
  масштабироваться, получает масштаб экрана до открытия и рисует чётко;
  при переносе окна на экран с другим масштабом получает новый. Плагин,
  который не умеет, масштабирует Windows: размер правильный, картинка
  чуть мягче. Раньше такие плагины были крошечными или обрезанными.
- **Выбор для каждого плагина:** правый клик по кнопке Edit (вставка
  микшера) или Native editor (канал-инструмент) → Editor scaling:
  Automatic / Plugin scales itself / Windows scales it. Открытое окно
  переоткрывается с новым режимом; выбор запоминается.
- Окно больше не мерцает и не показывает мусор вокруг интерфейса
  плагина.
- Размер клиентской области точно равен размеру плагина при любом
  масштабе (раньше рамка «съедала» низ и правый край).
- Окно плагина принадлежит окну jdance: остаётся поверх него и
  сворачивается вместе с ним.
- Клавиатура и колесо мыши идут в плагин, когда его окно активно.

## Окна плагинов (все системы)

- Окно подстраивается под размер, который плагин выбрал при открытии
  или позже, даже если он не сообщил о нём.
- Плагин, который умеет менять размер, получает окно с изменяемым
  размером.

## Плагины, которые не открывались

- Хост передаёт плагинам всё, что они ожидают (JUCE, iPlug и другие):
  контекст хоста фабрике, `IPlugInterfaceSupport`,
  `IComponentHandler2`, `IUnitHandler`, `IProgress`, обработчик до
  загрузки состояния, список выходных событий.
- Сообщения между частями плагина из других потоков больше не роняют
  программу.
- Плагины, отвечающие «не реализовано» на необязательные вопросы
  настройки, открываются.
- Смена задержки плагина обновляет компенсацию, не пересоздавая плагин:
  окно остаётся открытым, звук не прерывается.
- Список параметров обновляется, когда плагин меняет их названия или
  программы.

## Загрузка модулей

- Бандл `.vst3`, папку которого переименовали, загружается.
- Windows: плагины, чьи библиотеки находятся через PATH, загружаются;
  отсутствующая библиотека больше не показывает системное окно,
  блокирующее программу; причина отказа понятна («нет нужной
  библиотеки — переустановите плагин или Visual C++ Redistributable»,
  «не 64-битный плагин» и т. п.).
- Сканер ждёт модуль до 90 секунд (было 30: большие плагины попадали в
  чёрный список при первом сканировании).

## Известные ограничения

- Режим масштабирования выбирается только на Windows; на macOS и Linux
  окна масштабирует система.
- Плагин, у которого не создаётся контроллер (часть с параметрами и
  окном), по-прежнему не открывается.
- Остальное — как в 0.2.7.1.
