# jdance 0.2.1 — сэмплы из библиотеки в Playlist и удаление правой кнопкой

Исправления и удобство работы мышью поверх 0.2.0. Формат проекта не
изменился: проекты 0.2.0 открываются как есть.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.2.1-windows-x64.msi` и запустите; установка поверх
0.2.0 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

## Новое и исправленное

- **Сэмплы из библиотеки в Playlist.** Перетаскивание WAV из Browser
  (папки библиотеки, избранное, поиск) на дорожку Playlist снова создаёт
  аудиоклип в месте отпускания, с привязкой к сетке; ниже последней
  дорожки — новая дорожка. Во время перетаскивания показывается, куда
  ляжет клип. Раньше бросок не срабатывал.
- **Удаление правой кнопкой**, во всех инструментах:
  - Playlist — клипы паттернов, аудиоклипы и клипы автоматизации;
  - Piano Roll — ноты;
  - Automation Editor — точки.

  Клик правой кнопкой удаляет объект под курсором; если держать кнопку и
  вести мышь, удаляется всё, над чем прошёл курсор, даже при быстром
  движении. Весь жест — один шаг отмены (Ctrl+Z).
- **Меню клипа** в Playlist открывается маркером ▾ в начале полосы имени
  клипа или по Shift + правый клик.
- **Форма сегмента автоматизации** (Step, Linear, Curve) — правый клик
  между точками в Automation Editor.
- Раздел «Audio assets» в панели проекта Browser теперь считает и
  аудиоклипы Playlist.
