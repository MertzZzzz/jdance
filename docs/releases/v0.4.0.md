# jdance 0.4.0 — новый интерфейс

Первый выпуск редизайна интерфейса 2026 года. Логика программы и формат
проекта не меняются: изменились компоновка, визуальный язык и удобство.
Спецификация — [docs/spec/ui-redesign-2026.md](../spec/ui-redesign-2026.md)
(UI-RD), макеты — [docs/design/redesign-2026](../design/redesign-2026/).

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.4.0-windows-x64.msi` и запустите; установка поверх
0.3.6 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта: **20**, как в 0.3.6. Проекты открываются без изменений.

## Новое

- **Визуальная система** (UI-RD §1): новые токены палитры Graphite
  (подсветка гаммы индиго, `SCALE_UI`, `PREVIEW`, `SLIDE`), шкала шрифтов
  IBM Plex, собственный набор иконок с борда «R2 · Иконки» на всех
  кнопках, общие компоненты: сегментные группы, ручки, лампы, чипы,
  плашки клавиш, шапки панелей с Undock / Close, каретка и playhead.
- **Главное окно** (§2): верхняя строка 34 px с меню (появилось Help),
  быстрыми Save / Undo / Redo / Export, именем проекта и точкой
  несохранённых изменений; панель транспорта в одну строку — табло
  BAR·BEAT·TICK / BPM / SIG / TAP, метроном, отсчёт, Panic, паттерн с
  New / Rename / Clone / Loop, Snap-магнит, переключатели окон с
  F-клавишами, DSP и уровень выхода; строка состояния с подсказкой об
  элементе под курсором и значением регулятора при движении.
- **Browser**: вкладки Files / Plugins / History, поиск с иконкой.
- **Channel Rack** (§3): шапка с фильтром-чипом, строки 36 px с полосой
  выделения, кнопка-имя с иконкой типа и состоянием (muted / empty /
  missing / not found), кнопка Piano Roll в строке, шаги с заливкой по
  velocity группами по 4, зона сброса с кнопками слева, контекстное меню
  с иконками и клавишами.
- **Playlist** (§2.2): инструменты сегментной группой, вертикальные
  вкладки источников «иконка над подписью», клипы паттернов показывают
  ноты с высотой.
- **Mixer** (§2.3): полосы 74 px, фейдер в своей колонке рядом с
  индикатором L/R (колпачок не перекрывает шкалу), пунктирная полоса
  «+ New track», посылы и sidechain — канатики со стрелкой у входа
  получателя и уровнем на канатике; инспектор с карточками эффектов и
  ручкой Dry/Wet.
- **Piano Roll** (§5): шапка Tools / Snap / инструменты / Stamp / Slide /
  канал / паттерн, клавиатура 56 px с подписью каждой клавиши, полоса
  Velocity с уровнями 32 / 64 / 96 / 127, карточка выделения, подсветка
  гаммы индиго с точками на клавишах.
- **Окно канала** (§4): вкладки-иконки и верхняя полоса ON / PAN / VOL /
  PITCH / TRACK на всех вкладках.
- **Диалоги** (§7): основная кнопка янтарная справа, Cancel — контурная;
  новый вид Tap Tempo.

### Новое поведение (UI-RD §10)

- **Открепление Browser и Channel Rack** (§10.1) — кнопка Undock в шапке
  или View › Own windows.
- **Клавиши окон**: F5 Playlist, F6 Channel Rack, F9 Mixer, Alt+F8
  Browser (F7 Piano Roll и F8 выбор плагина — как раньше).
- **Горячие клавиши Tools** в Piano Roll (§10.6): Ctrl+Q, Ctrl+Shift+Q,
  Alt+Q, Ctrl+Shift+L, Ctrl+U; диалоги Alt+R / H / L / U / G / A / S /
  F / W / M / I / N / V; LFO Alt+O, Transpose Alt+T, Scale Alt+K, Note
  properties Alt+Enter. Клавиши показаны в меню Tools.
- **Ноты вне гаммы** обводятся (§10.8).
- **Окно канала**: стрелки «предыдущий / следующий канал» (§10.4).

## Известные ограничения

- Перенесена не вся спецификация. Ещё не сделаны: ручка Swing (§10.3,
  нужна поддержка в движке), создание посылов перетаскиванием канатика
  (§10.2 — канатики пока только показывают посылы), перетаскиваемые точки
  ADSR (§10.5), предпросмотр и Listen для Tools (§10.7), счётчик в «Fit
  notes to scale», мини-обзор Sample Editor (§10.9), новинки Automation
  Editor, Export, MIDI и Audio settings (§10.10–13); раскладка
  содержимого вкладок сэмплера, Sample Editor, Automation Editor и
  мелких диалогов — в прежнем виде с новыми цветами и кнопками.
- Вид проверен скриншотами под Linux (Xvfb); на Windows вручную не
  проверялся.
