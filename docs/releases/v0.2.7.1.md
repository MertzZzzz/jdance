# jdance 0.2.7.1 — исправлены Ctrl+C и Ctrl+V в piano roll

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.2.7.1-windows-x64.msi` и запустите; установка поверх
0.2.7 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта не менялся (17): проекты 0.2.7 и 0.2.7.1 взаимозаменяемы.

## Исправлено

- **Ctrl+C, Ctrl+X и Ctrl+V в piano roll** не работали в установленной
  программе: Windows передаёт Ctrl+V программе, только когда в системном
  буфере обмена есть текст, а копирование нот туда ничего не клало.
  Теперь копирование нот кладёт в системный буфер строку
  «jdance: N note(s)», и вставка срабатывает. Сами ноты по-прежнему
  берутся из внутреннего буфера jdance.
- Если после копирования нот скопировать текст в другой программе,
  Ctrl+V в piano roll всё равно вставит последние скопированные ноты.

## Известные ограничения

- Как в 0.2.7.
