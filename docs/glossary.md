# Глоссарий (CR-004)

Названия элементов интерфейса jdance и соответствующие общие термины DAW.
Наши названия не должны совпадать с фирменными названиями плагинов и
функций других продуктов. Общеотраслевые термины (piano roll, playlist,
mixer, step sequencer) допустимы.

| В интерфейсе jdance | Общий термин | Примечание |
|---|---|---|
| Channel Rack | список каналов со step sequencer | **решить**: термин распространён, но ассоциируется с одним продуктом; кандидат на замену — «Channels» |
| Channel | канал инструмента (сэмплер или плагин) | |
| Pattern | паттерн | |
| Piano Roll | piano roll | общий термин |
| Playlist | аранжировщик, timeline | общий термин в pattern-based DAW |
| Lane / Track (Playlist) | дорожка аранжировки | не связана с треком микшера |
| Clip | клип паттерна / аудио / автоматизации | |
| Mixer | микшер | |
| Track (Mixer) | канал микшера, insert | «Master» — главный выход |
| Send | посыл | sidechain = посыл с уровнем 0 % |
| Insert / Effect slot | слот эффекта | 8 на трек |
| Browser | браузер файлов и ресурсов | |
| Sampler | встроенный сэмплер | |
| Parametric EQ, Tempo Delay, Reverb, Compressor, Safety Limiter | встроенные эффекты | собственные названия |
| Snap | привязка к сетке | |
| Hint bar | строка подсказок | |
