# Спецификация 0.3.6: слайд-ноты на каналах VST3

2026-11-01 · @Mertz

Продолжение [spec-0.3.5](spec-0.3.5.md) §9: слайд-ноты ведут высоту и у
VST3-инструментов. В FL Studio слайды работают только с собственными
инструментами (руководство Image-Line, `html/pianoroll.htm`); для
VST-плагинов там советуют моно-режим с портаменто самого плагина. Здесь
jdance идёт дальше FL: всё поведение ниже — решения jdance **[Н]**,
построенные на открытом VST3 SDK (Note Expression, `IMidiMapping`).

## Как передаётся высота

| Способ | Когда | Что отправляется |
|---|---|---|
| **Note Expression «Tuning»** | плагин реализует `INoteExpressionController` и объявляет тип `kTuningTypeID` на шине 0, канале 0 | на каждую ноту отдельно: `NoteExpressionValueEvent` с её `noteId`, значение `0.5 + полутоны / 240` (стандартный диапазон Tuning ±120 полутонов) |
| **MIDI pitch bend** | иначе, если `IMidiMapping` назначает `kPitchBend` (контроллер 129) на шине 0, канале 0 | параметр плагина, назначенный на pitch bend: `0.5 + полутоны / (2 · диапазон)`, обрезка до 0…1; общий для всех нот канала |
| — | плагин не поддерживает ни то, ни другое | слайды не слышны (как в 0.3.5) |

## Требования

| № | Требование | Приоритет |
|---|---|---|
| 1 | Слайд-нота на канале VST3 не отправляется плагину как нота (не звучит сама) | P0 |
| 2 | Те же правила, что у сэмплера (spec 0.3.5 §8.2–8.8): действует на звучащие ноты секвенсора этого канала (не живые с клавиатуры), верхняя приходит к высоте слайда к концу слайд-ноты, остальные сдвигаются на тот же интервал, слайды складываются, слайд в одном тике с нотой действует на неё | P0 |
| 3 | Высота меняется линейно в полутонах (экспоненциально по частоте): точки каждые 64 сэмпла и точное конечное значение в конце слайда | P0 |
| 4 | Отправка поверх нот: в одном смещении сначала note-off, затем note-on, затем изменения высоты | P0 |
| 5 | Новая нота (не слайд) после слайда звучит на своей высоте: если ранее отправлялось ненулевое смещение, вместе с note-on отправляется смещение 0 (для pitch bend — возврат колеса в центр) | P0 |
| 6 | Канал VST3 получает настройку **Pitch bend range** (полутоны, 1–48, по умолчанию 2) в окне канала; она должна совпадать с диапазоном bend в самом плагине. Для Note Expression она не используется | P0 |
| 7 | Поле канала `pitch_bend_range` в файле (по умолчанию 2 — не пишется); `format_version` 20, миграция 19 → 20 ничего не меняет | P0 |
| 8 | Способ выбирается при создании экземпляра плагина и не меняется до его пересоздания | P0 |
| 9 | Без аллокаций в аудиопотоке; переполненный список событий отбрасывает лишние точки (RT-011) | P0 |

## Критерии приёмки

- Тест `engine`: слайд на канале с инструментом даёт события Tuning с
  нарастающим значением и точным конечным; новая нота после слайда
  получает Tuning 0; слайд не превращается в note-on.
- Тест `plugin-vst3` (тестовый синтезатор с Note Expression Tuning):
  частота голоса после слайда на октаву — вдвое выше.
- Тест `plugin-vst3` (тестовый синтезатор только с pitch bend):
  параметр bend получает `0.5 + 12/(2·12) = 1.0` при диапазоне 12.
- Тест `persistence`: диапазон сохраняется; файл v19 читается с
  диапазоном 2.
