# ADR-013: Граф микшера, порядок обработки, закон панорамы

- Статус: ACCEPTED
- Дата: 2026-10-20
- Требования: MIX-001…MIX-061

## Решение

**Модель.** Узлы — mixer tracks и master. Рёбра: main out (у каждого
трека ровно один), sends (0…16), sidechain (источник → insert на другом
треке). Граф с учётом всех трёх видов рёбер ацикличен; проверка в
`Mixer::validate`, команда с циклом отклоняется до изменения документа,
в ошибке — путь цикла.

**Порядок.** Топологическая сортировка (Kahn) с устойчивым порядком по
документу; master всегда последний. Весь граф обрабатывается в одном
audio thread (MVP). Многопоточность — после MVP.

**Лимиты.** 256 каналов, 128 треков + master, 16 sends и 10 inserts на
трек. Буферы под эти лимиты выделяются при создании движка (~5 МБ).

**Signal flow трека.** вход → inserts → pre-fader tap → fader
(громкость × balance) → post-fader tap → mute → main out.
Pre-fader sends берутся из pre-fader tap и не зависят от fader и mute;
post-fader sends — после mute. Sidechain не зависит от mute источника.

**Закон панорамы (MIX-013).**
- Каналы (моно-источники в стерео): constant power, −3 dB в центре.
- Треки и master (стерео-шины): balance, 0 dB в центре, линейное
  ослабление противоположной стороны.

Причина: constant power на каждой шине давал −3 dB на каждом уровне
вложенности (канал → трек → master = −9 dB).

**PDC (MIX-030).** Компиляция snapshot считает задержку на входе и выходе
каждого трека, задержки на рёбрах канал → трек, main out, sends,
задержки sidechain и pre-delay перед insert'ом, если sidechain приходит
позже основного сигнала. Максимум на ребро — 2^17 сэмплов; превышение
урезается и показывается в UI.

**Состояние при пересборке.** Сглаженные гейны, содержимое delay lines
и состояние эффектов переносятся из старого snapshot по стабильным ID
обменом буферов (`take_state_from`), без аллокаций на audio thread.
Поэтому правка громкости не даёт щелчка и не сбрасывает задержки.

## Последствия

- Golden render изменился ровно в √2 раз (master balance вместо −3 dB);
  проверено сравнением старого и нового файла (max ошибка 8e-8).
- Solo (MIX-012): solo-in-place, слышны solo-трек, его источники и путь
  к master по main out и sends; sidechain не затрагивается.
- Перенос состояния — O(n²) по объектам, n ≤ сотни; при росте числа
  объектов заменить на сопоставление по отсортированным ключам.
