# jdance 0.2.4 — каретка тянется, выделение времени, каретка паттерна, рендер выделения

Каретку теперь можно тянуть мышью по линейке, а Shift делает выделение
времени: его можно двигать, тянуть за края и рендерить в файл. У
паттерна появилась своя каретка; в режиме Song Piano Roll идёт вместе с
песней. Моно/стерео входа переключается прямо на полосе микшера.
Исправлен выбор знаменателя размера такта.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.2.4-windows-x64.msi` и запустите; установка поверх
0.2.3 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

## Исправлено

- Поле размера такта: знаменатель (2, 4, 8, 16) выбирается кнопками;
  раньше список знаменателя не открывался.

## Каретка на линейке Playlist

- Нажмите на линейку и ведите: каретка идёт за мышью, у края окна вид
  прокручивается. Во время воспроизведения звук переходит на каретку,
  когда кнопка отпущена.
- Esc во время жеста возвращает всё как было.

## Выделение времени

- **Shift + перетаскивание** по линейке — выделение. Границы ставятся на
  любую долю такта (или мельче, по Snap); Alt отключает привязку.
  Каретка идёт за мышью, а после отпускания встаёт на начало выделения,
  и Loop включается.
- **Shift + перетаскивание внутри выделения** переносит его целиком;
  у края — тянет только этот край.
- **Двойной клик** по линейке сбрасывает выделение.
- Правый клик по линейке: Clear selection, Select whole song, Render
  selection….

## Рендер выделения

- В File › Export audio появился диапазон **Selection** (и пункт Render
  selection… в меню линейки).
- Фрагмент звучит так же, как в песне: ноты, начатые раньше, и хвосты
  эффектов попадают в файл. После конца выделения новые ноты не
  начинаются, аудиоклипы затухают, дальше — хвост (Tail).
- Имя файла по умолчанию — «<проект> (bars 5-9).wav».

## Каретка паттерна и Piano Roll в режиме Song

- В режиме Pattern у паттерна своя каретка: ставится и тянется по линейке
  Piano Roll и табло позиции. Play начинается с неё, следующие круги — с
  начала паттерна; Stop возвращает на неё, повторный Stop — в начало.
  Смена паттерна ставит каретку в начало.
- В режиме Song Piano Roll и Channel Rack показывают курсор и каретку
  песни внутри клипа паттерна: на каждом повторе паттерна курсор
  возвращается в начало. Клик по линейке Piano Roll ставит каретку песни
  в это место клипа.

## Микшер: моно/стерео входа

- На полосе трека с входом рядом с кнопкой входа — кнопка **M/S**: «In 1»
  ↔ «In 1+2», прослушивание не выключается.
- Правый клик по кнопке входа — список входов; у трека без входа —
  кнопка «—» с тем же списком.

## Известные ограничения

- Входы треков, M/S и прослушивание не проверялись на реальном
  устройстве и ASIO-драйвере.
- Выделение времени одно на весь Playlist; в Piano Roll выделения
  времени нет.
- Остальное — как в 0.2.3.
