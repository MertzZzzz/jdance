# jdance 0.3.1 — окна инструментов VST3 снова открываются

Исправление: инструменты VST3, добавленные через «+ Channel → Instrument
(VST3)», зависали с чёрным окном редактора.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.3.1-windows-x64.msi` и запустите; установка поверх
0.3.0 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта не менялся (18).

## Исправление

- **Чёрное зависшее окно инструмента.** В 0.3.0 модуль плагина
  загружался в фоновом потоке (чтобы ускорить открытие проектов с
  тяжёлыми плагинами). Плагины на JUCE и других фреймворках привязывают
  цикл сообщений своих окон к потоку, в котором их инициализировали
  (`InitDll`, фабрика); после окончания фонового потока их редактор не
  рисовался и не отвечал. Теперь модуль, как до 0.3.0, загружается в
  потоке интерфейса, а в фоне только читается его файл — так загрузка
  по-прежнему не ждёт диска.

## Известные ограничения
