# Редизайн jdance 2026 — материалы для реализации

Здесь всё, что нужно, чтобы перенести согласованный редизайн в код
(`crates/ui`, egui 0.37). Дизайн утверждён владельцем проекта
2026-11-01; реализация ещё не начата.

**Главный документ — спецификация
[docs/spec/ui-redesign-2026.md](../../spec/ui-redesign-2026.md) (UI-RD).**
Этот README — карта материалов и порядок работы.

## Что лежит в папке

| Папка | Содержимое |
|---|---|
| `boards/` | PNG всех бордов дизайна (1:1, размеры из `source/canvas.json`) — смотреть в первую очередь |
| `source/` | исходники бордов (`*.dc.html`) и `canvas.json` с канваса Claude Design; числа (размеры, цвета, отступы) брать отсюда |
| `current/` | скриншоты текущей версии 0.3.6 (demo-проект) для сравнения «до / после» |

Исходники `*.dc.html` — HTML с инлайн-стилями; в `renderVals()` внизу
каждого файла — данные и вычисление геометрии (ручки, волны, ноты). Для
рендера им нужен runtime Claude Design (`support.js`), его в репозитории
нет — для просмотра есть PNG.

## Решения владельца, которые легко потерять

- Логика программы не меняется; всё новое поведение — только из UI-RD §10,
  все пункты §10 **одобрены**.
- Палитра Graphite, шрифты IBM Plex; цвет подсветки гаммы — **синий
  (индиго)**, но элементы управления гаммой (точки на клавишах, метка,
  окно Scale) — зелёные `SCALE_UI`.
- Иконки на **всех** кнопках.
- Все панели, кроме Playlist, открепляются (Browser и Rack — новое).
- Фейдер микшера не перекрывает индикатор уровня.
- Посылы — канатики со стрелкой **на конце** (у входа получателя),
  без стрелок посередине.
- Каретка (янтарный треугольник + пунктир) во всех окнах со шкалой
  времени, кроме Sample Editor (там своей каретки нет).
- Инструменты как в коде: Playlist — Draw, Paint, Delete, Slice, Select,
  Speed; Piano Roll — Draw, Paint, Delete, Slice, Select, Mute. Не
  добавлять Zoom / Playback.
- Окно сэмплера — раскладка по референсу расположения; Variants, Load
  regions, Load slice markers **не** добавлять (их нет в jdance).
- Круг выбора цвета: сетка ячеек из `jdance_domain::color`
  (12 × 4 + 12 серых) не меняется; разделители — тонкие полупрозрачные
  белые линии, не тёмные зазоры.
- Мелкие диалоги без макета оформлять в коде в общем стиле (UI-RD-070).
- Clean-room (CR-002): у стороннего референса взято только расположение
  элементов; не копировать его цвета, иконки и вид контролов.

## Порядок работы

Этапы — UI-RD §11; каждый этап отдельным PR.

1. Основа: `theme.rs` (токены), `icons.rs` (глифы из `R2Icons`), общие
   виджеты.
2. Главное окно.
3. Channel Rack и Playlist.
4. Mixer.
5. Piano Roll.
6. Окно сэмплера и настройки канала.
7. Редакторы и диалоги.
8. Новая функциональность §10 — по пункту за раз.

Для каждого этапа: `cargo test`, `cargo clippy`, smoke-test GUI и
скриншоты «до / после» из запущенной программы.

## Как запустить и снять скриншот (Linux, без экрана)

```sh
sudo apt-get install -y libasound2-dev libjack-jackd2-dev libxkbcommon-x11-0 xvfb xdotool imagemagick
cargo build --release -p jdance-app
Xvfb :99 -screen 0 1600x1000x24 &
DISPLAY=:99 JDANCE_RENDERER=glow ./target/release/jdance assets/demo/demo.jdance &
sleep 10
# при первом запуске открывается Audio settings — закрыть крестиком:
DISPLAY=:99 xdotool mousemove 594 40 click 1
DISPLAY=:99 import -window root -crop 1440x900+0+0 shot.png
```

Окно настроек сэмплера открывается двойным кликом по имени канала в
Channel Rack (≈ 480, 205 на demo-проекте); вкладки — клик по заголовкам.
