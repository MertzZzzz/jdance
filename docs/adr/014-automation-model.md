# ADR-014: Модель автоматизации

- Статус: ACCEPTED
- Дата: 2026-10-21
- Требования: AUT-001..070 (Amendment 02, раздел 18), spec-mixer-playlist-effects
  (automation clips вне playlist MVP)

## Контекст

Amendment 02 требует автоматизацию громкости, pan, sends, параметров
встроенных эффектов (в том числе компрессора с sidechain), bypass и
параметров VST3 (сценарий 6a). Спецификация playlist исключает
automation clips из MVP. Форма хранения по AUT-001 — решение этого ADR.

## Варианты

1. Automation clips в playlist (как pattern clips).
2. Автоматизационные дорожки (lanes) на общей шкале песни, по одной
   на цель.

## Решение

Вариант 2. `Project.automation` — список дорожек; у каждой одна цель
и точки во времени песни (тики, PPQ 960). Дорожки показываются под
playlist на той же шкале. Это не clips и не нарушает out-of-scope
playlist.

- Точка: `tick`, `value` в [0, 1], кривая до следующей точки: `hold`,
  `linear` или `curve` с `tension` в [-1, 1]. Формула curve:
  `y = y0 + (y1 - y0) · t^e`, `e = 4^tension` (tension 0 = linear,
  > 0 — медленный старт, < 0 — быстрый).
- До первой точки — значение первой, после последней — значение
  последней (AUT-011). Совпадающие по времени точки: значение
  переключается на последнюю из них.
- Цели (AUT-002): громкость и pan трека, уровень send, параметр
  встроенного эффекта (по строковому ID схемы), bypass insert'а,
  параметр VST3 эффекта или инструмента (`ParamID`).
- Нормализованное значение переводится в значение цели: громкость
  `v · MAX_VOLUME`, pan `2v − 1`, send `v · MAX_SEND_LEVEL`,
  параметры эффектов — по mapping схемы (linear/log/toggle/choice),
  bypass — `v ≥ 0.5`, VST3 — как есть.
- Автоматизация действует только в режиме Song во время
  воспроизведения. В режиме Pattern и при остановленном transport
  действуют значения проекта (AUT-040: при остановке параметр
  меняется свободно). Запись автоматизации движением регуляторов —
  вне MVP (AUT-041).
- Удаление объекта удаляет его дорожки в той же команде; undo
  восстанавливает обе (AUT-050). Дорожка с несуществующей целью при
  загрузке сохраняется и помечается «цель не найдена».

Применение в engine (AUT-020/021/030):
- non-RT компилирует точки в сэмплы для текущего tempo;
- громкость, pan и send: значение вычисляется каждые 32 сэмпла,
  внутри — линейная интерполяция (hold-скачок растягивается на ≤ 32
  сэмпла ≈ 0.7 ms);
- параметры встроенных эффектов: события с offset каждые 32 сэмпла
  (сглаживание эффекта сверху);
- bypass: на границе блока (кроссфейд bypass уже есть);
- VST3: точка в начале каждого блока (chase, AUT-033), каждая точка
  огибающей с точным offset и промежуточные точки каждые 64 сэмпла.

## Последствия

- Automation в pattern-режиме не слышна; это показано в UI.
- Порядок «дорожка с меньшим индексом важнее» (AUT-012) не нужен:
  на цель одна дорожка.
