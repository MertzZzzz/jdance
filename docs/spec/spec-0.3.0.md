0.2.9). Поведение FL описано по официальному руководству Image-Line и

спорно, решение принято здесь и помечено «решение jdance».

## 1. Баг: Ctrl+C / Ctrl+V не работают

### Причина (найдена при разборе)

Клавиши редакторов (Ctrl+C, Ctrl+V, Delete, инструменты на одну букву,
стрелки) отключались, если `egui_wants_keyboard_input()` возвращал
`true`. В egui 0.37 эта функция истинна, когда фокус клавиатуры у
**любого** виджета, а не только у текстового поля: после клика по кнопке
(Play, Stop, выбор Snap, кнопки панели инструментов) фокус оставался на
ней, и все клавиши редакторов молчали до клика по пустому месту. Тесты
0.2.7.1 подавали события без сфокусированной кнопки и этого не видели.

Вторая причина — фокус клавиш у отстыкованного piano roll: нажатия в его
отдельном окне не попадали в ввод главного окна, и piano roll не получал
клавиши, пока виден плейлист.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 1.1 | Клавиши редакторов отключаются только при фокусе в текстовом поле (`text_edit_focused`), а не при фокусе на кнопке или списке | P0 |
| 1.2 | Ctrl+C / Ctrl+X / Ctrl+V работают в piano roll сразу после клика по любой кнопке главного окна | P0 |
| 1.3 | Фокус клавиш определяется нажатием внутри области редактора в **его** окне (главном или отстыкованном) | P0 |
| 1.4 | Автотест: кнопка в фокусе, затем Copy / Paste — ноты копируются и вставляются | P0 |

## 2. Баг: MIDI-файлы не импортируются и не перетаскиваются

### Причины

- Ctrl+M в 0.2.9 был занят глобальной клавишей метронома, которая
  забирала нажатие раньше piano roll.
- Перетаскивание из браузера проверяло отпускание на виджете сетки, а
  во время перетаскивания egui считает «наведённым» перетаскиваемый
  элемент, поэтому отпускание не регистрировалось.
- Файл, брошенный из системы, требовал свежей позиции указателя; при
  перетаскивании из Проводника Windows позиция не обновляется.
- `.mid`, брошенный на плейлист, молча игнорировался.

### Как в FL

- Ctrl+M в piano roll — импорт MIDI-файла; в остальных окнах Ctrl+M —
  метроном (сочетания зависят от окна).
- MIDI-файл можно перетащить в piano roll или на плейлист; на плейлисте
  он становится паттерном.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 2.1 | Ctrl+M при фокусе клавиш в piano roll открывает импорт MIDI; в остальных случаях — метроном | P0 |
| 2.2 | Перетаскивание `.mid` из браузера на piano roll вставляет ноты в место броска (по Snap) | P0 |
| 2.3 | `.mid` из системы, брошенный на окно piano roll, вставляется в место броска, а если позиция неизвестна — на каретку | P0 |
| 2.4 | `.mid` на плейлисте: новый паттерн с именем файла, ноты — в канал piano roll, иначе в выбранный канал-инструмент или сэмплер, иначе в новый канал-сэмплер; клип паттерна ставится в место броска; один шаг Undo | P0 |
| 2.5 | Меню File › Import MIDI file… (то же, что 2.4, в начало песни на новую дорожку) | P1 |

## 3. Баг: «The MIDI file has no notes»

### Причина

Читатель останавливался после числа треков из заголовка. Часть программ
пишет в заголовок формата 1 неверное число треков (например, 1 при двух
треках: трек темпа и трек нот) — тогда читался только трек темпа без нот.
Кроме того, не поддерживались файлы в обёртке RIFF (RMID), системные
сообщения 0xF1…0xFE внутри трека и треки с неверной длиной чанка.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 3.1 | Читаются все чанки `MTrk` до конца файла, независимо от числа в заголовке | P0 |
| 3.2 | Длина чанка больше остатка файла — читается до конца; длина 0 у непустого трека — трек читается до следующего `MTrk` | P0 |
| 3.3 | Файлы RMID (`RIFF…RMID…data`) читаются по вложенному `MThd` | P0 |
| 3.4 | Системные сообщения 0xF1, 0xF2, 0xF3, 0xF6, 0xF8…0xFE внутри трека пропускаются с правильной длиной | P0 |
| 3.5 | Если нот действительно нет, сообщение называет число треков и событий («2 tracks, 0 notes») | P1 |

## 4. Кнопка Play не переключает активное окно

Решение jdance (руководство FL этого не описывает, но в FL транспорт не
меняет окно, в котором работают клавиши): клик по Play, Stop, Record и
другим кнопкам панели транспорта не меняет фокус клавиш. После клика по
Play клавиши piano roll или плейлиста продолжают работать там, где
работали.

| № | Требование | Приоритет |
|---|---|---|
| 4.1 | Кнопки панели транспорта не забирают фокус клавиатуры (фокус снимается сразу после клика) | P0 |
| 4.2 | Фокус клавиш меняется только нажатием внутри piano roll, плейлиста или браузера (§1.3) | P0 |
| 4.3 | Space по-прежнему запускает и останавливает воспроизведение из любого окна | P0 |

## 5. Кнопка назначения канала (микшерного трека) в окне сэмплера

### Как в FL

В настройках канала есть поле TRACK — микшерный трек канала; команда
«Route to free mixer track» (Ctrl+L в меню настроек канала) направляет
канал на первый свободный трек микшера.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 5.1 | В окне сэмплера рядом с TRACK — кнопка «→ Free track»: канал направляется на первый трек микшера без каналов и эффектов; если такого нет — создаётся новый трек с именем канала | P0 |
| 5.2 | То же — пункт «Route to free mixer track» в правом меню канала Channel Rack, для всех выделенных каналов (каждому свой трек) | P0 |
| 5.3 | Один шаг Undo; после назначения микшер показывает выбранный трек | P0 |

## 6. Прокрутка по горизонтали и вертикали «за мышкой»

### Как в FL

Колесо прокручивает окно под указателем; Shift+колесо — по горизонтали;
Ctrl+колесо — масштаб. В piano roll прокрутка средней кнопкой по обеим
осям (0.2.7 §1).

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 6.1 | Колесо прокручивает область под указателем (плейлист, piano roll, Channel Rack, микшер, браузер), без клика для фокуса | P0 |
| 6.2 | Shift+колесо — горизонтальная прокрутка во всех этих областях; горизонтальное колесо и тачпад — по обеим осям | P0 |
| 6.3 | Средняя кнопка и перетаскивание прокручивают вид за мышью по обеим осям в плейлисте, piano roll, Channel Rack и микшере | P0 |
| 6.4 | При перетаскивании клипа, ноты или рамки выделения у края вида вид прокручивается вслед за мышью; скорость растёт с заходом за край | P0 |
| 6.5 | Ctrl+колесо — масштаб, как раньше | P0 |

## 7. Правый клик по зелёному индикатору — соло

### Как в FL

Руководство Image-Line о микшере: левый клик по индикатору (mute switch)
выключает и включает трек, правый клик — соло трека. Тот же жест работает
для дорожек плейлиста.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 7.1 | Правый клик по зелёному индикатору дорожки плейлиста — соло этой дорожки; повторный правый клик снимает соло | P0 |
| 7.2 | Правый клик по зелёному индикатору трека микшера — соло трека (с путём к мастеру, как кнопка Solo); повторный — снимает | P0 |
| 7.3 | Соло видно на индикаторе (обводка цвета акцента); одно соло заменяет другое (эксклюзивно), Ctrl+правый клик добавляет к соло | P0 |
| 7.4 | Левый клик по-прежнему выключает и включает (mute) | P0 |
| 7.5 | Один шаг Undo на клик | P0 |

## 8. Тяжёлые плагины, загружающие много с диска

### Исследование

- Медленная загрузка тяжёлых инструментов почти всегда — работа самого
  плагина: чтение сэмплов, тысячи мелких чтений файлов, разбор больших
  состояний (форумы HISE, VI-Control, JUCE). Хост не может ускорить чтение
  плагина, но может (а) не блокировать интерфейс, (б) не загружать плагин
  повторно без нужды, (в) распараллелить то, что плагину не мешает.
- Спецификация VST3 и опыт хостов: создание компонентов, `setState` и
  связь с контроллером ожидаются в UI-потоке; часть хостов вызывает
  `getState` в фоне при офлайн-рендере, что приводит к взаимоблокировкам
  у некоторых плагинов (форум JUCE). Поэтому создание экземпляров
  остаётся в UI-потоке.
- Загрузка самой библиотеки модуля (`dlopen` / `LoadLibrary` и
  статическая инициализация крупных бинарников) с UI не связана и может
  идти в фоне.
- Большие состояния (десятки–сотни МБ) замедляют открытие проекта
  (форум JUCE: MainStage — минуты при ~100 МБ).

### Что делает jdance

| № | Требование | Приоритет |
|---|---|---|
| 8.1 | Файлы модулей плагинов проекта читаются в фоновом потоке при открытии проекта (прогрев кеша ОС); сам модуль (`InitDll`, `ModuleEntry`, фабрика) загружается только в потоке интерфейса — уточнено в 0.3.1: плагины на JUCE привязывают цикл окон к потоку инициализации | P0 |
| 8.2 | Экземпляры создаются постепенно: не больше одного тяжёлого создания за кадр (бюджет ~50 мс на кадр), интерфейс отвечает; до готовности инструмент молчит, эффект пропускает звук | P0 |
| 8.3 | Строка состояния показывает «Loading plugins 3/12 · Kontakt» до конца загрузки | P0 |
| 8.4 | Время создания каждого экземпляра измеряется; плагин дольше 2 с отмечается в окне Plugins («slow to load: 4.2 s») | P1 |
| 8.5 | Экземпляр не пересоздаётся из-за правок, не касающихся плагина (уже так), и при повторном открытии того же проекта модули не выгружаются, пока живы экземпляры | P0 |
| 8.6 | Смена частоты без пересоздания экземпляра (deactivate → setupProcessing → activate) | P2 |
| 8.7 | Экспорт без вторых офлайн-экземпляров для плагинов, которые это допускают | P2 |

## 9. Выбранный клип передаёт своё состояние новым

Решение jdance: руководство FL говорит, что карандаш ставит источник,
выбранный в панели или кликом по клипу (0.2.7 §2); здесь клик по клипу
выбирает ещё и его состояние.

| № | Требование | Приоритет |
|---|---|---|
| 9.1 | Клик по клипу делает его образцом: карандаш и кисть ставят копии с его состоянием | P0 |
| 9.2 | Для клипа сэмпла копируются: отрезок файла (обрезка), скорость, громкость, фейды | P0 |
| 9.3 | Для клипа паттерна копируются: длина, смещение внутри паттерна, зацикливание | P0 |
| 9.4 | Для клипа автоматизации: отрезок источника | P0 |
| 9.5 | Выбор источника в браузере проекта или селекторе паттернов сбрасывает образец (клип по умолчанию) | P0 |
| 9.6 | Состояние mute не копируется | P0 |

## 11. Открытый паттерн переключает вход на свой инструмент

### Как в FL

MIDI-клавиатура и «клавиатура как пианино» играют выбранный канал;
открытие piano roll канала выбирает этот канал.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 11.1 | Двойной клик по клипу паттерна открывает piano roll канала, у которого в этом паттерне есть ноты или шаги (первый сверху); если таких нет — прежнее правило | P0 |
| 11.2 | Открытие piano roll (любым способом) выбирает его канал в Channel Rack | P0 |
| 11.3 | Вход (MIDI-клавиатура, клавиатура как пианино) играет канал открытого piano roll, иначе выбранный канал Channel Rack | P0 |
| 11.4 | Смена паттерна при открытом piano roll переключает его на инструмент этого паттерна по правилу 11.1 | P1 |

## 12. MIDI-вход

### Как в FL

Окно MIDI settings: список входов, кнопка Enable у каждого, Rescan; данные
принимаются в режиме Omni (все 16 каналов); играет выбранный канал;
индикатор активности мигает при приёме.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 12.1 | Окно Options › MIDI settings: список входов системы, флажок Enable у каждого, Rescan; выбор сохраняется в настройках | P0 |
| 12.2 | Windows (WinMM), macOS (CoreMIDI), Linux (ALSA) — через библиотеку `midir` | P0 |
| 12.3 | Note On / Note Off (Note On с velocity 0 — Off) со всех каналов (Omni) играют канал из §11.3 с velocity/127 | P0 |
| 12.4 | Индикатор MIDI на панели транспорта мигает при приёме | P0 |
| 12.5 | Устройство, пропавшее при работе, отключается без падения; при появлении снова — подключается по Rescan | P0 |
| 12.6 | Ноты, звучащие при смене целевого канала, заканчиваются на прежнем канале | P0 |
| 12.7 | Задержка: от прихода сообщения до команды движку — без ожидания кадра интерфейса (поток MIDI будит интерфейс) | P0 |
| 12.8 | Sustain (CC64), pitch bend, запись нот в piano roll | P1 |
| 12.9 | Привязка контроллеров к параметрам (MIDI learn), выход MIDI | P2 |

## Формат проекта

Не меняется (18). Настройки MIDI и плагинов — в настройках программы.

## Проверка

- Клик по Play, затем в piano roll Ctrl+C и Ctrl+V — ноты вставляются у
  каретки.
- Ctrl+M в piano roll открывает импорт MIDI, в плейлисте — метроном.
- Файл формата 1 с заголовком «1 трек» и двумя треками читается с нотами.
- `.mid` на плейлисте создаёт паттерн и клип; Ctrl+Z убирает оба.
- Правый клик по зелёному индикатору трека микшера — соло; повтор — снято.
- Shift+колесо над Channel Rack прокручивает по горизонтали; средняя
  кнопка тащит вид плейлиста.
- Клик по обрезанному клипу, затем карандаш — новый клип той же длины.
- Проект с несколькими плагинами открывается, интерфейс отвечает,
  строка состояния показывает ход загрузки.
- Нота с MIDI-клавиатуры звучит на канале открытого piano roll.
