# jdance 0.2.0 — аудиоклипы, запись и инструменты Piano Roll

Вторая версия jdance: pattern-based DAW на Rust, независимая clean-room
реализация. Лицензия GPL-3.0-or-later.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.2.0-windows-x64.msi` и запустите. Установщик ставит
программу в `Program Files\jdance`, добавляет ярлык в меню «Пуск»,
связывает файлы `.jdance` с jdance и кладёт демо-проект в
`Program Files\jdance\demo`. Удаление — через «Приложения и возможности».

Установщик не подписан: Windows SmartScreen может показать
предупреждение «Неизвестный издатель» — «Подробнее» → «Выполнить в любом
случае». Контрольная сумма — в файле `.sha256` рядом с установщиком.

Проекты 0.1.0 открываются и переводятся в формат 12; рядом остаётся
резервная копия старого файла.

## Новое

- **Аудиоклипы в Playlist**: перетаскивание WAV из Browser и системы,
  копия в папке проекта `assets/`, waveform, маршрут дорожки в трек
  микшера, изменение длины за оба края, Slice, Sample Editor по двойному
  клику.
- **Инструменты Draw, Paint, Delete, Slice, Select** с иконками и общей
  раскладкой клавиш в Playlist и Piano Roll; клипы паттернов с offset,
  длиной и loop.
- **Project Browser** слева от Playlist: паттерны, сэмплы и
  автоматизации проекта; перетаскивание в Playlist.
- **Папки библиотеки** с подпапками, фоновым индексом и диалогом выбора
  сэмпла.
- **Автоматизация клипами**: источники автоматизации и клипы в Playlist,
  Automation Editor, автоматизация gain аудиоклипа.
- **Запись** одного входа (mono или стереопара) на выбранную дорожку,
  индикатор входа, мониторинг по желанию, ручная поправка задержки,
  восстановление незавершённых записей после сбоя.
- **Экспорт MP3** (LAME, 128–320 кбит/с, 44,1/48 кГц, title/artist) и
  прогресс/отмена экспорта.
- **Плагины**: стандартные и свои папки VST3 с включением/отключением,
  прогресс и отмена сканирования, список ошибок.
- **Окна**: Piano Roll, Sample Editor, Automation Editor, Mixer и Project
  Browser выносятся в отдельные окна (View › Own windows).
- **Piano Roll Tools**: Riff machine, chord progression, legato,
  articulate, quantize (быстрый, по началам, с swing и groove), chop,
  glue, arpeggiate, strum, flam, claw machine, limit, flip, randomize,
  scale levels, LFO; скрипты на Rhai (Arpeggiator, Euclidean, Humanize,
  Note repeater sprinkler, Select by velocity and more) и своя папка
  скриптов.
- **Mixer** по новой схеме: вертикальные полосы и панель свойств
  выделенного трека.

## Известные ограничения

- Нет ASIO: звук через WASAPI.
- Загружаются только WAV-файлы.
- Запись с реального оборудования, выравнивание записи по времени,
  отдельные окна на Windows/macOS, несколько мониторов и HiDPI в среде
  разработки не проверялись (см. статус).
- Последние настройки инструментов Piano Roll помнятся только до выхода
  из программы.
- Ресемплинг сэмплов без anti-aliasing.
