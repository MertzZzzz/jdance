# Редизайн интерфейса (UI-RD)

Статус: согласовано с владельцем проекта, 2026-11-01. Дополняет
[ui-visual-spec.md](ui-visual-spec.md) и заменяет его там, где речь идёт о
внешнем виде окон. Поведение и логика программы не меняются, кроме пунктов
§10 («Новая функциональность»), — каждый из них отдельная задача.

Макеты: канвас Claude Design «jdance — редизайн» (раунды R1–R5). PNG и
исходники бордов — в [docs/design/redesign-2026](../design/redesign-2026/);
ниже каждый раздел ссылается на борд по имени.

**UI-RD-001. Принцип.** Сохраняем всю логику работы; меняем компоновку,
визуальный язык и удобство. Новые возможности (§10) реализуются только
после отдельного решения.

**UI-RD-002. Clean-room.** Скриншоты стороннего продукта использовались
только как референс *расположения* элементов (окно сэмплера, R3). Палитра,
иконки, вид контролов и тексты — свои (CR-002, UI-VIS-002).

## 1. Визуальная система

### 1.1. Палитра

Палитра «Graphite» (UI-VIS §2.1) сохраняется. Изменения и новые токены:

| Токен | Значение | Назначение |
|---|---|---|
| `SCALE_ROW` | #1A1D2C | строка ноты гаммы в Piano Roll (было #18241F) |
| `SCALE_TONIC` | #242A48 | строка тоники; слева полоса 3 px `SCALE_ACCENT` |
| `SCALE_ACCENT` | #9AA5FF | полоса тоники, подпись «tonic» |
| `OUT_OF_SCALE` | `ERROR` #FF9C8F | обводка 2 px ноты вне гаммы |
| `PREVIEW` | `TEAL` #3CC9B0 | предпросмотр и прослушивание результата инструмента |
| `SLIDE` | #B48CF0 | слайд-ноты и кнопка Slide (уже в коде) |
| `SCALE_UI` | #6FCF97 | элементы управления гаммой: точки на клавишах, метка «C minor», выбор в окне Scale |
| `OVERLAY` | #2B3038 | фон под плавающими окнами на макетах (в программе не нужен) |

Роли цвета (UI-VIS-020) действуют дальше. Добавлено: бирюзовый также
обозначает «предпросмотр / слушать результат».

### 1.2. Типографика

IBM Plex Sans / Mono без изменений. Шкала (борд R2 · Главное окно,
«шрифты из B»):

| Стиль | Размер |
|---|---|
| Заголовок панели | Sans SemiBold 12.5 |
| Текст элементов | Sans 12 |
| Подпись секции | Sans 9–10, верхний регистр, разрядка 1 px, `MUTED` |
| Значения, позиции, клавиши | Mono 9.5–12 |
| Табло позиции | Mono 18, `AMBER` |

### 1.3. Геометрия

- Радиусы: кнопки и поля 6–7, карточки секций 9, окна 10, меню 9–10.
- Высота строки управления 26–32; шапка панели 32; табло 38.
- Карточка секции: фон #13161A, рамка #22272D, отступ 10–12, заголовок —
  иконка 12 + подпись секции.

### 1.4. Иконки

Свой набор (борд R2 · Набор иконок), сетка 16×16, линия 1.5 px, рисуется
фигурами egui (расширение `icons.rs`, `Glyph`). Иконки есть на **всех**
кнопках: транспорт, режимы, окна, вкладки, инструменты, действия диалогов.
Группы: транспорт и проект; окна (+ Undock, Dock, Close); инструменты
редакторов (Draw, Paint, Delete, Mute, Slice, Select, Speed); браузер и
источники; микшер и эффекты; паттерн и каналы; Stamp, Slide, Scale, LFO.
Snap — магнит (янтарный) со стрелкой списка.

### 1.5. Общие компоненты

| Компонент | Описание |
|---|---|
| Шапка панели | 32 px: иконка, заголовок, « › » контекст, элементы панели; справа Undock и Close |
| Сегментная группа | подложка `FIELD`, рамка `LINE`, кнопки 22–30 px, активная `RAISED` или `BLUE_BG` + рамка `BLUE` |
| Ручка | диск `FIELD`, кольцо `LINE_STRONG`, дуга 2.4–3 px; громкость `AMBER`, pan/pitch `TEXT` (от центра), dry/wet `BLUE`; размеры 20/22/28/34/44 |
| Лампа | Ø 8–10, `LED_ON` с ореолом / `LED_OFF` |
| Переключатель | 28×16, вкл. `LED_ON` (или `SCALE_UI`, `AMBER` по контексту) |
| Чип | высота 22–26, радиус 11–13; вкл. `BLUE_BG` + рамка `BLUE` |
| Плашка клавиш | Mono 9.5, фон #171A1E, рамка #2F353D, радиус 4 |
| Каретка | треугольник `AMBER` на линейке + пунктир `AMBER` 1 px через сетку; во всех окнах со шкалой времени (Playlist, Piano Roll, Automation Editor) |
| Playhead | сплошная 2 px #F2F4F6 |
| Строка подсказок | внизу главного окна: описание элемента под курсором и значение регулятора при движении |

## 2. Главное окно (борд R2 · Главное окно)

**UI-RD-010. Верхняя строка, 34 px:** логотип, меню File / Edit / View /
Options / Help, быстрые иконки Save / Undo / Redo / Export, по центру имя
проекта и точка несохранённых изменений, справа устройство и буфер.

**UI-RD-011. Панель транспорта, 52 px, одна строка:**
1. Play / Stop / Record — одна сегментная группа;
2. PAT / SONG с иконками;
3. табло: BAR·BEAT·TICK (янтарное), BPM, SIG, TAP;
4. метроном, отсчёт, Panic (иконки), точка MIDI;
5. паттерн: цвет, имя, длина ▾, кнопки New / Rename / Clone / Loop;
6. Snap (магнит + значение ▾);
7. переключатели окон — иконка + F-клавиша: Browser F8, Rack F6,
   Piano F7, Playlist F5, Mixer F9;
8. DSP % с полосой и индикатор выхода.

**UI-RD-012. Строка состояния, 24 px:** состояние сохранения, голоса,
строка подсказок по центру, устройство и частота справа.

**UI-RD-013. Раскладка панелей:** Browser слева, Channel Rack сверху,
Playlist в центре, Mixer снизу. Все панели, кроме Playlist, открепляются
(Browser, Channel Rack, Piano Roll, Mixer и уже открепляемые редакторы).

### 2.1. Browser

Вкладки с иконками **Files / Plugins / History**, поиск, предпрослушивание
снизу. Во вкладке Files остаются все текущие разделы: Favorites, Project
(Patterns, Instruments, Audio assets, Automation, Effects), Library,
Locations.

### 2.2. Playlist

- Инструменты: Draw (P), Paint (B), Delete (D), Slice (C), Select (E),
  Speed (S) — ровно как в коде.
- Источники слева: вертикальные вкладки «иконка над подписью» Patterns /
  Samples / Auto, фильтр, список; вкладки не выходят за ширину панели.
- Клипы паттернов показывают ноты **с высотой** (мини-превью по строкам).
- Каретка и playhead по §1.5.

### 2.3. Mixer (вид из варианта B)

- Полоса 74 px: цветной кант, номер, лампа, имя, значки FX и Arm, pan,
  фейдер, индикатор L/R, значение дБ.
- **Фейдер в своей колонке 20 px**, колпачок 18×10 центрирован, отступ
  8 px до индикатора — колпачок никогда не перекрывает шкалу.
- В конце ряда пустая пунктирная полоса «+ New track».
- Полоса маршрутизации под полосками: посылы — «канатики» (см. §10.2).
- Инспектор справа, 250 px: эффекты выбранного трека (лампа, иконка,
  имя, тип, **ручка Dry/Wet** с процентами), «+ Effect», сводка посылов;
  у Master — Safety limiter.

## 3. Channel Rack (борд R3 · Channel Rack)

- Шапка: меню, иконка, «Channel Rack › паттерн ▾», длина в шагах,
  счётчик выбранных, фильтр All / Instruments / Audio, вид Steps / Notes,
  «+ Channel», очистка неиспользуемого аудио, Dock / Close.
- Строка 36 px: полоса выделения 4 px, лампа ON, ручки PAN / VOL / PITCH
  (22 px), номер трека, кнопка-имя 180 px (полоса цвета, иконка типа,
  имя, значок состояния: muted / missing / empty / not found), кнопка
  Piano Roll.
- Шаги 23×28, заливка по velocity, текущий шаг в рамке, группы по 4.
- Каналы-инструменты показывают мини-полосу нот с высотой.
- Зона сброса: кнопки Sampler / Sampler from file… / VST3 instrument… у
  **левого** края, подсказка про перетаскивание — справа, приглушённо.
- Контекстное меню канала — с иконками и клавишами.

## 4. Окно сэмплера (борды R3 · Sampler)

Раскладка вкладки Sample — по референсу расположения (UI-RD-002):

- верх: вкладки-иконки Channel / Sample / Instrument / Envelope слева;
  справа ON, PAN, VOL, PITCH, RANGE, TRACK;
- левая колонка: File (путь, загрузить, показать в браузере, очистить),
  Content (Keep on disk, Resample, Declicking ▾), Playback
  (One-shot / Loop, Gain);
- правая колонка: Time stretching (PITCH, MUL, TIME, Mode ▾), Precomputed
  effects (6 переключателей + ручки SMP START, LENGTH, IN, OUT,
  CROSSFADE, TRIM);
- низ: волна во всю ширину — линия сигнала с градиентной заливкой и
  огибающей, метки START / END, часть за END приглушена.

Вкладки Channel / Instrument / Envelope — борд R3 · Sampler tabs; при
реализации получают ту же верхнюю полосу, что и Sample.

## 5. Piano Roll (борды R2 · Piano Roll, R5 · Stamp, R5 · Scale, R5 · Tools)

- Шапка: меню, Tools ▾, Snap, инструменты Draw / Paint / Delete / Slice /
  Select / Mute, **Stamp ▾** (янтарная с именем штампа, когда выбран),
  **Slide**, «Piano Roll › канал ▾», Ghost, паттерн ▾.
- Клавиатура 56 px: подписана **каждая** клавиша, мягкие градиенты вместо
  жёстких линий; чёткая граница только у C.
- Каретка и playhead по §1.5.
- Полоса Velocity: линии 25 / 50 / 75 / 100 % с подписями 32 / 64 / 96 /
  127, столбик с круглой шляпкой, значение у выделенных нот.
- Карточка сводки выделения в правом нижнем углу сетки.
- Меню Stamp: Only one, (none) Shift+N, Automatic chord, аккорды плитками
  + подменю Advanced (20), Scales (32), Percussions (Fill, Flam, Roll +
  dynamic / relative), Special → Slide up. Призрак штампа под курсором с
  меткой «Cm7 · 2 beats».
- Подсветка гаммы: §1.1 (`SCALE_*`), точки на клавишах гаммы, метка гаммы
  в шапке.
- Меню Tools — все пункты кода с иконками и плашками клавиш (§10.6).

## 6. Редакторы (борды R4)

- **Sample Editor:** Play / Stop, сведения о файле одной строкой, чип
  выделения, Use as clip range / Place in Playlist / Load into Sampler
  (+ выбор канала), мини-обзор, L / R, IN / OUT, линейка в секундах.
- **Automation Editor:** имя, бирюзовый чип цели, длина, Snap, масштаб,
  шкала значений в единицах параметра, огибающая с заливкой, всплывающее
  значение точки, меню формы сегмента Step / Linear / Curve + Tension,
  каретка, подсказки с плашками клавиш.

## 7. Диалоги (борды R4 · Audio, R5)

Audio settings, Export audio + прогресс, Plugins + выбор плагина (F8),
Quantize (живое превью, Listen), Transpose, Tap Tempo, Color, MIDI
settings, Recording, Scale — как на бордах. Общие правила: заголовок с
иконкой, карточки секций, основная кнопка `AMBER` справа внизу, Cancel —
контурная, разрушительные действия — `ERROR`.

**UI-RD-070. Диалоги без макета** — оформляются в коде по общим
правилам выше, без отдельного раунда дизайна (решение владельца):
Pattern name presets (`name_presets_ui.rs`), Scripts (`scripts.rs`),
LFO (`lfo_dialog.rs`), Library folders и Sample Selection Dialog
(`library.rs`), Note properties и прочие диалоги Piano Roll
(`piano_dialogs.rs`, `note_tools_ui.rs`), окна восстановления записи
(`recording.rs`), MIDI settings, Exporting, окно Color (`color_picker.rs`).
Для LFO и инструментов Tools — превью на сетке и Listen по §10.7.

## 10. Новая функциональность

Внешний вид выше реализуется без изменения логики. Пункты ниже меняют
поведение — каждый отдельной задачей и только после подтверждения.
Пометки: **[подтв.]** — владелец одобрил на макете; **[подтв.]** —
нужно уточнение.

1. **Открепление Browser и Channel Rack** (`dock::Panel`). [подтв.]
2. **Канатики посылов в микшере.** Порты: выход — точка справа под
   полосой, вход — овал слева. Тянуть из порта на трек — новый посыл;
   правый клик по канатику — изменить / удалить. Посыл — сплошной, цвет
   градиентом от источника к получателю, стрелка-наконечник на конце у
   входа; sidechain — пунктир; уровень — плашка на канатике. Логика
   посылов прежняя, новое — способ создания. [подтв.]
3. **Ручка Swing** в шапке Channel Rack (в UI-VIS отложена до v2). [подтв.]
4. **Сэмплер:** стрелки «предыдущий / следующий канал»; «Open in Sample
   Editor» для сэмпла канала. [подтв.]
5. **Envelope:** точки ADSR на графике можно тянуть. [подтв.]
6. **Горячие клавиши инструментов Tools** (сейчас нет): Ctrl+Q,
   Ctrl+Shift+Q, Alt+Q (из UI-VIS-073); Ctrl+Shift+L, Ctrl+U; диалоги
   Alt+R / H / L / U / G / A / S / F / W / M / I / N / V, LFO Alt+O,
   Transpose Alt+T, Scale Alt+K, Note properties Alt+Enter. Не
   пересекаются с занятыми (Ctrl+A/B/C/D/T/V/X в Piano Roll, Ctrl+L/M/N/O/
   P/S/Y/Z глобально, буквы без модификатора). [подтв.]
7. **Предпросмотр инструмента на сетке** при наведении на пункт Tools,
   **Listen** (пробел) — прослушать результат, **A / B** — удержание
   играет оригинал. [подтв.]
8. **Гамма:** обводка нот вне гаммы и счётчик в «Fit notes to scale». [подтв.]
9. **Sample Editor:** мини-обзор с прокруткой и масштабом (UI-VIS-039)
   вместо ползунка Zoom. [подтв.]
10. **Automation Editor:** всплывающее значение точки, шкала значений,
    кнопка LFO… (окно LFO сейчас открывается из Piano Roll). [подтв.]
11. **Export:** строка файла в диалоге (сейчас системный диалог после
    Export…) и уведомление «Exported… · Show in folder». [подтв.]
12. **MIDI settings:** переключатель у каждого входа. [подтв.]
13. **Audio settings:** частота и буфер сегментными кнопками; строки
    Input на макете не будет — входное устройство выбирается в окне
    Recording, как сейчас.

Не принято: вкладки-«workspaces» и командная палитра Ctrl+K (вариант C).

## 11. План переноса в код

Каждый этап — отдельный PR, проверка: `cargo test`, smoke-test GUI,
скриншот до/после.

1. **Основа:** токены `theme.rs` (§1.1), шкала шрифтов, новые глифы
   `icons.rs`, общие виджеты (ручка, лампа, сегменты, чип, переключатель,
   плашка клавиш, шапка панели, карточка секции, каретка).
2. **Главное окно:** верхняя строка, панель транспорта в одну строку,
   строка состояния, Browser с вкладками.
3. **Channel Rack и Playlist** (включая превью нот с высотой в клипах).
4. **Mixer:** полосы, фейдер в своей колонке, инспектор с Dry/Wet;
   отображение посылов канатиками (без создания перетаскиванием).
5. **Piano Roll:** клавиатура, Velocity, Stamp / Slide в шапке, меню
   Tools, подсветка гаммы.
6. **Окно сэмплера и настройки канала.**
7. **Редакторы и диалоги** (R4, R5).
8. **Новая функциональность** §10 — по одному пункту.
