# jdance 0.2.9 — сэмплер на плейлисте, скорость клипа, MIDI-файлы

Сэмпл на плейлисте теперь — клип сэмплера: двойной клик открывает
сэмплер, его настройки слышны в клипе. Новый инструмент Speed меняет
скорость клипа, MIDI-файлы вставляются в piano roll, библиотеку можно
листать стрелками. Клипы больше не съезжают с ритма при смене темпа.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.2.9-windows-x64.msi` и запустите; установка поверх
0.2.8 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта — 18 (у сэмплера появился файл клипов, у аудиоклипа —
скорость). Проекты 0.2.8 открываются без изменений; jdance 0.2.8 файлы
формата 18 не открывает.

## Сэмплер на плейлисте

- **Сэмпл по умолчанию — в сэмплер.** Файл, брошенный на плейлист из
  библиотеки или из системы, кладётся в новый сэмплер, а на плейлисте
  появляется клип этого сэмплера. Тот же файл ещё раз — ещё один клип
  того же сэмплера. Всё это — один шаг Undo.
- **Сэмплер из Channel Rack — на плейлист.** Перетащите имя канала-
  сэмплера на дорожку: появится его клип. Если сэмпл ещё не в проекте,
  он сначала импортируется.
- **Клип звучит через сэмплер.** Tools (обращение, нормализация, фейды),
  PITCH, MUL, TIME «Project tempo» и GAIN сэмплера сразу слышны в клипах;
  длина клипа следует MUL и TIME.
- **Двойной клик по клипу открывает сэмплер** вместо Sample Editor.
  Аудиоканал из старого проекта при этом становится сэмплером с тем же
  файлом (звук не меняется, Ctrl+Z возвращает как было). Sample Editor
  по-прежнему открывается двойным кликом по файлу в библиотеке и с полосы
  аудиоканала.
- Ноты и шаги такого сэмплера работают как раньше.

## Инструмент Speed

- Новая кнопка на панели инструментов плейлиста, клавиша **S**.
  Перетаскивание клипа сжимает его (быстрее, выше) или растягивает
  (медленнее, ниже), как плёнку; ×0.25…×4, по сетке (Alt — без сетки).
- Скорость у каждого клипа своя, на клипе видна метка «×1.50». Двойной
  клик инструментом Speed возвращает ×1.
- Растянуть без смены высоты можно в сэмплере: MUL или TIME.

## MIDI-файлы

- **Ctrl+M** или кнопка **Import MIDI…** в piano roll вставляют ноты
  MIDI-файла справа от каретки, как Ctrl+V: вставленные ноты выделены,
  паттерн удлиняется при необходимости.
- Файл `.mid` можно перетащить на piano roll из библиотеки или из
  системы — ноты лягут в место броска.
- Читаются форматы 0, 1 и 2; ноты всех треков идут в канал piano roll.
  Темп файла не применяется (о нём сообщается).

## Библиотека

- **↑ / ↓** выбирают предыдущий и следующий файл и сразу проигрывают
  его (если включено автопрослушивание); список прокручивается к нему.
  Стрелки работают, когда последний клик был в библиотеке.
- MIDI-файлы видны в библиотеке.

## Исправления

- **Сэмпл не попадал в ритм после смены темпа.** Начало аудиоклипа
  хранилось в абсолютном времени: при смене темпа сетка тактов
  сдвигалась, а клип нет. Теперь клипы остаются на своих тактах; Ctrl+Z
  возвращает их точно на прежнее место. Сам сэмпл при этом не
  растягивается и не ресемплится.
- **Stop** на панели транспорта останавливает превью сэмпла из
  библиотеки, даже когда воспроизведение уже остановлено.

## Известные ограничения

- У сэмплера с клипами на плейлисте нельзя заменить сэмпл (средний
  клик, Load sample): сначала удалите клипы.
- Волна клипа сэмплера рисуется по исходному файлу, без обработки.
- Многотрековый MIDI-файл вставляется в один канал; экспорта MIDI и
  MIDI-клавиатур пока нет.
- ← / → в библиотеке папки не сворачивают.
- Остальное — как в 0.2.8.
