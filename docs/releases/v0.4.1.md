# jdance 0.4.1 — редизайн завершён

Второй выпуск редизайна интерфейса 2026 года: перенесены оставшиеся окна
и диалоги, сделана вся новая функциональность из UI-RD §10, которая в
0.4.0 значилась в известных ограничениях. Спецификация —
[docs/spec/ui-redesign-2026.md](../spec/ui-redesign-2026.md) (UI-RD),
макеты — [docs/design/redesign-2026](../design/redesign-2026/), скриншоты
«после» — в `after/` там же.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.4.1-windows-x64.msi` и запустите; установка поверх
0.4.0 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта: **21** (был 20) — добавлен Swing. Проекты 0.4.0 и старше
открываются без изменений (Swing 0 %). Проект, сохранённый в 0.4.1,
0.4.0 не откроет.

## Новое поведение (UI-RD §10)

- **Swing** (§10.3) — ручка SWING в шапке Channel Rack, 0–100 %: каждый
  второй шаг step sequencer'а звучит позже, до половины шага; конец ноты
  инструмента остаётся на следующем шаге сетки. Ноты Piano Roll не
  сдвигаются. Хранится в проекте, рендер и экспорт его учитывают.
- **Посылы канатиками** (§10.2) — тяните из выходного порта (точка под
  полосой микшера) на другую полосу: появится посыл. Получатель
  подсвечивается, если посыл возможен (нет петли и посыла туда ещё нет).
  Правый клик по плашке уровня на канатике — уровень, 0 / −6 / −12 дБ,
  pre / post, удаление.
- **Окно сэмплера** (§10.4–10.5): кнопка в углу волны открывает сэмпл
  канала в Sample Editor; в карточке File — загрузить, показать в папке,
  очистить. Точки ADSR на графике Envelope можно тянуть (шкала времени не
  «прыгает», пока тянете).
- **Tools в Piano Roll** (§10.7): наведение на пункт меню Tools
  показывает результат прямо на сетке с последними настройками
  инструмента; плашка «Preview · Quantize · 3 of 12 changed». В окне
  инструмента **Listen** (или пробел) зацикливает паттерн с результатом,
  не меняя проект; удержание **A / B** играет оригинал.
- **Гамма** (§10.8): в окне Scale кнопка «Fit notes to scale» показывает,
  сколько нот она сдвинет.
- **Sample Editor** (§10.9): вместо ползунка Zoom — мини-обзор всего
  файла: рамку видимой части можно тянуть, её края — масштаб, клик —
  переход, двойной клик — весь файл; Ctrl+колесо — масштаб у курсора,
  колесо — прокрутка; линейка в секундах.
- **Automation Editor** (§10.10): шкала значений в единицах параметра
  слева, всплывающее значение точки с позицией, кнопка **LFO…** (окно LFO
  раньше открывалось только из Piano Roll).
- **Export** (§10.11): файл выбирается прямо в диалоге (строка File и
  Change…; по умолчанию рядом с проектом), Export пишет без второго
  диалога; по окончании — уведомление «Exported demo.wav» с кнопкой
  **Show in folder**.
- **MIDI settings** (§10.12): у каждого входа — переключатель и лампа
  активности.
- **Audio settings** (§10.13): частота и размер буфера — сегментными
  кнопками; частоты, которых нет у устройства, приглушены.

## Перенос дизайна

- Окно сэмплера (R3): вкладка Sample — карточки File, Content, Playback
  (ручка Gain), Time stretching и Precomputed effects (ручки и
  переключатели), волна во всю ширину с метками START / END; вкладки
  Channel, Instrument и Envelope — по борду R3 · Sampler tabs.
- Sample Editor (R4): транспорт, сведения о файле, чип выделения,
  действия справа, метки IN / OUT, подсказки внизу.
- Automation Editor (R4): чип цели, заливка под огибающей, меню формы
  сегмента карточками Step / Linear / Curve с Tension, подсказки с
  плашками клавиш.
- Audio settings (R4): плашка состояния потока, карточки Device и
  Format, сведения о потоке, Close device слева и Apply справа с
  отметкой о непримененных изменениях.
- Export, прогресс и уведомление (R5); Plugins (R5): пути переключателями,
  баннер сканирования, вкладки Found / Failed; MIDI settings, Recording,
  Scale, Transpose (R5).

## Известные ограничения

- Каретка в Automation Editor не показывается (у источника автоматизации
  своё время, не связанное с кареткой Playlist).
- Окна LFO, Pattern name presets, Scripts и Library folders оформлены
  общими компонентами без отдельной перекладки (UI-RD-070); превью LFO
  на сетке нет.
- Listen играет паттерн целиком, начиная с каретки паттерна; в режиме
  Song на время прослушивания транспорт переходит в режим паттерна и
  возвращается после.
- Вид проверен скриншотами под Linux (Xvfb); на Windows вручную не
  проверялся.
