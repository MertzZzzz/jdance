# jdance 0.3.4 — плагины отвечают, окно не чернеет

Исправления: VPS Avenger не реагировал на клики, а после закрытия его окна
окно jdance становилось чёрным и переставало обновляться; Addictive Drums
переставал загружать биты.

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.3.4-windows-x64.msi` и запустите; установка поверх
0.3.3 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта не менялся (18).

## Исправления

- **Кнопки плагинов «не работали» (VPS Avenger).** Пока открыто окно
  плагина или идёт воспроизведение, jdance перерисовывается каждый кадр,
  и у его окна всегда ждёт перерисовка. Таймеры Windows срабатывают,
  только когда никаких других сообщений нет, — поэтому таймеры плагинов не
  срабатывали никогда. Avenger перерисовывает себя по таймеру: клики
  доходили, но окно не менялось. Теперь jdance каждый кадр сам запускает
  наступившие таймеры.
- **Addictive Drums не загружал биты.** Та же причина: плагины на JUCE
  загружают содержимое по таймеру. Пустая полоса бита, молчащее превью и
  MIDI без нот при перетаскивании из 0.3.3 больше не повторяются.
- **Чёрное окно jdance после закрытия Avenger.** Avenger рисует через
  OpenGL в том же потоке, что и интерфейс jdance. Закрываясь, он удаляет
  свои текстуры, не переключившись на свой контекст, — и удалял текстуры
  jdance: окно становилось чёрным, а Windows через несколько секунд
  сообщала, что программа не отвечает. Теперь на время каждого вызова
  плагина контекст jdance снимается, а затем возвращается.

Проверено вручную с VPS Avenger 1.4.10 (лицензия активирована):
вкладки, ручки, «+» осцилляторов и огибающих, файлы, повторное открытие и
закрытие окна; Addictive Drums 2: биты загружаются.
