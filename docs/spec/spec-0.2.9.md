# Спецификация 0.2.9: сэмплер на плейлисте, скорость клипа, MIDI-файлы, листание библиотеки

2026-10-23 · @Mertz

Изменения релиза 0.2.9 для clean-room реимплементации FL (поверх 0.2.8).
Поведение описано по руководству FL Studio и пожеланиям заказчика;
формулировки, названия и алгоритмы — наши. Код FL не используется.

## Обзор

| № | Изменение | Как в FL | Решение для jdance |
|---|---|---|---|
| 1 | Сэмплер на плейлисте | Сэмпл, брошенный на плейлист, становится каналом Audio Clip с настройками, похожими на сэмплер; клип — экземпляр канала | Клип плейлиста может быть экземпляром канала-сэмплера; канал из Channel Rack можно бросить на плейлист |
| 2 | Двойной клик открывает сэмплер | Двойной клик по аудиоклипу открывает настройки его канала | Вместо Sample Editor открывается окно сэмплера (настройки канала) |
| 3 | Сэмпл по умолчанию — в сэмплер | — | Файл, брошенный на плейлист, кладётся в новый сэмплер, а на плейлисте лежит клип этого сэмплера |
| 4 | Инструмент «Скорость» | Растяжение клипа при изменении длины (режим растяжения в меню плейлиста) | Инструмент на панели плейлиста: перетаскивание меняет скорость клипа |

| 6 | MIDI-файлы | Import → MIDI file; перетаскивание .mid в piano roll | Импорт `.mid` в piano roll (Ctrl+M, меню, перетаскивание из библиотеки и из системы) |
| 7 | Листание библиотеки стрелками | ↑/↓ в браузере выбирают соседний файл и проигрывают его | То же; ←/→ сворачивают и раскрывают папку |

Приоритеты: **P0** — в релиз, **P1** — по возможности, **P2** — позже.

## 1. Сэмплер на плейлисте

### Модель

- Канал-сэмплер может иметь **файл клипов** — импортированный в проект
  аудиофайл (asset). Его клипы на плейлисте — экземпляры канала, как у
  аудиоканалов 0.2.2 (ACH): громкость, панорама, трек микшера и эффекты
  канала действуют на все клипы.
- Сэмпл такого сэмплера — тот же файл; при сохранении проекта файл
  копируется в `assets/`, и путь сэмпла меняется вместе с ним.
- Клип играет сэмпл **с обработкой сэмплера**: Tools (обращение,
  нормализация, фейды и т. д.), PITCH, MUL, TIME (подгонка к темпу) и
  режим растяжения, а также усиление сэмплера (GAIN). Ноты и шаги этого
  канала по-прежнему играют сэмпл как обычный сэмплер.
- Длина клипа на плейлисте = длина выбранного отрезка файла × MUL (или
  длина по TIME) ÷ скорость клипа (§4). Если включён TIME «Project
  tempo», длина клипа следует темпу.
- Панорама канала с файлом клипов — баланс, как у аудиоканалов: в
  центре уровень не меняется, поэтому клип звучит так же громко, как
  раньше аудиоклип.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 1.1 | Перетаскивание канала-сэмплера с сэмплом из Channel Rack на плейлист создаёт его клип в месте броска (с привязкой к сетке); пустое место под дорожками создаёт новую дорожку | P0 |
| 1.2 | Если у сэмплера ещё нет файла клипов, его сэмпл импортируется в проект (в фоне), канал получает файл клипов, затем ставится клип — одним шагом Undo | P0 |
| 1.3 | Сэмплер без сэмпла и канал-инструмент на плейлист не бросаются; подсказка объясняет почему | P0 |
| 1.4 | Карандаш и кисть ставят клипы активного сэмплера (активный источник, как в 0.2.7 §2) | P0 |
| 1.5 | Клик по клипу сэмплера выбирает канал в Channel Rack; правое меню клипа: «Open sampler», «Make unique», «Automate gain» | P0 |
| 1.6 | Make unique для клипов сэмплера делает копию сэмплера с теми же настройками | P1 |
| 1.7 | Изменение настроек сэмплера сразу слышно в его клипах; длина клипов на плейлисте обновляется | P0 |
| 1.8 | Замена сэмпла сэмплера (средний клик) у канала с клипами: клипы играют новый сэмпл, их длина считается по прежнему файлу (ограничение релиза) | P1 |
| 1.9 | Обратная совместимость: аудиоканалы старых проектов работают как прежде | P0 |

## 4. Инструмент «Скорость» (Speed)

В FL длина аудиоклипа меняется с растяжением, если включён режим
растяжения. У нас это отдельный инструмент на панели инструментов
плейлиста.

| № | Требование | Приоритет |
|---|---|---|
| 4.1 | Кнопка «Speed» на панели инструментов плейлиста, клавиша **S** (при фокусе на плейлисте) | P0 |
| 4.2 | Перетаскивание клипа (сэмплера или аудиоканала) по горизонтали меняет его длину от левого края; скорость = прежняя длина ÷ новая; высота меняется вместе со скоростью, как у плёнки | P0 |
| 4.3 | Диапазон скорости ×0.25…×4; при перетаскивании действует привязка (Alt отключает), подсказка показывает «×1.25» | P0 |
| 4.4 | Скорость хранится в клипе (у каждого клипа своя); на клипе со скоростью ≠ 1 видна метка «×1.25» | P0 |
| 4.5 | Двойной клик инструментом Speed возвращает скорость ×1 | P1 |
| 4.6 | Жест — один шаг Undo; скорость действует в воспроизведении и экспорте одинаково | P0 |
| 4.7 | Растяжение без смены высоты — через MUL/TIME в сэмплере (§1) | P1 |

## 6. MIDI-файлы

### Как в FL

- Импорт MIDI-файла в piano roll (меню Piano Roll → File → Import MIDI
  file, Ctrl+M) кладёт ноты в текущий паттерн и канал.
- Файл можно перетащить из браузера в piano roll.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 6.1 | Читаются Standard MIDI Files форматов 0 и 1 (тип 2 — как 1), деление в тиках на четверть; SMPTE-деление отклоняется с понятной причиной | P0 |
| 6.2 | Ноты (note on/off, note on с velocity 0 как off), running status, мета- и SysEx-события пропускаются корректно; незакрытые ноты заканчиваются в конце трека | P0 |
| 6.3 | Время пересчитывается в 960 PPQ; velocity 1…127 → 0…1; высоты 0…127 как есть (60 = C5) | P0 |
| 6.4 | Ctrl+M и кнопка «Import MIDI…» в piano roll открывают выбор файла; ноты всех треков и каналов вставляются в канал piano roll **справа от каретки**, как вставка Ctrl+V (0.2.7 §1 п. 8–9): самая левая нота на каретке, вставленные выделены, паттерн удлиняется по общим правилам | P0 |
| 6.5 | Перетаскивание `.mid` из библиотеки или из системы на piano roll вставляет ноты в место броска (по горизонтали, с привязкой) | P0 |
| 6.6 | Библиотека показывает `.mid`/`.midi`; клик выделяет файл (без превью), подсказка говорит, куда его бросить | P0 |
| 6.7 | Вставка — один шаг Undo; ноты сверх лимита паттерна (16 тактов) отбрасываются с предупреждением | P0 |
| 6.8 | Темп из файла не меняет темп проекта (сообщается в уведомлении) | P1 |
| 6.9 | Импорт многотрекового файла в отдельные каналы и паттерны; экспорт MIDI; MIDI-клавиатуры и контроллеры | P2 |

## 8. Баг: сэмпл не попадает в ритм после смены темпа

### Причина

Начало аудиоклипа хранилось в кадрах (абсолютное время). При смене темпа
сетка тактов сдвигалась, а клип оставался на месте: клип, положенный на
такт 5 при 130 BPM, при 140 BPM начинался между долями. Звук самого
сэмпла не менялся, но «съезжал» с ритма.

### Требования

| № | Требование | Приоритет |
|---|---|---|
| 8.1 | Смена темпа сохраняет положение клипов в тактах и долях: начало каждого аудиоклипа пересчитывается в кадры нового темпа | P0 |
| 8.2 | Отмена и повтор смены темпа возвращают клипы точно на прежние кадры (без накопления округлений при перетаскивании поля темпа) | P0 |
| 8.3 | Сэмпл при этом не растягивается и не ресемплится: высота и длина неизменны, если в сэмплере не включён TIME | P0 |
| 8.4 | Клип сэмплера с TIME «Project tempo» меняет длину вместе с темпом и остаётся в такт | P0 |

## Формат проекта

Версия 18: у канала — необязательный файл клипов (`clip_asset`), у
аудиоклипа — скорость (`speed`, по умолчанию 1). Миграция 17→18 ничего
не меняет; старые версии программы файлы 18 не открывают.

## Проверка

- Сэмпл, брошенный на плейлист, создаёт сэмплер и его клип; второй бросок
  того же файла добавляет клип того же сэмплера; Ctrl+Z убирает всё.
- Канал-сэмплер из Channel Rack, брошенный на плейлист, звучит с
  обработкой сэмплера (PITCH +12 — на октаву выше).
- Двойной клик по клипу открывает окно сэмплера; для старого аудиоканала
  канал становится сэмплером, рендер до и после совпадает.
- Инструмент Speed: клип, сжатый вдвое, играет вдвое быстрее; длина ×0.5.
- Stop при остановленном транспорте глушит превью.
- MIDI-файл формата 1 с двумя треками вставляется справа от каретки;
  running status и note on с velocity 0 разбираются верно.
- ↓ в браузере выбирает и проигрывает следующий файл.
- Клип на такте 5 при 130 BPM после смены на 140 BPM начинается на такте 5;
  Undo возвращает исходные кадры точно.
