# ADR-001: Лицензия приложения

- Статус: ACCEPTED
- Дата: 2026-10-20
- Требования: LIC-001…LIC-008, BLD-011, ASIO-002, PLG-006

## Контекст

Владелец продукта выбрал GPL (Amendment 02, ревизия 2). Нужно выбрать
версию и следствия для зависимостей и SDK.

## Решение

- Лицензия всего репозитория — **GPL-3.0-or-later**.
- GPL-2.0-only исключена: несовместима с Apache-2.0 (cpal, hound и
  многие транзитивные зависимости) и с GPLv3-веткой ASIO SDK.
- Каждый `.rs` файл начинается с `// SPDX-License-Identifier: GPL-3.0-or-later`;
  проверяется `cargo xtask check`.
- Лицензии зависимостей проверяет `cargo deny` по списку из `deny.toml`.

## Открыто

- Механизм приёма внешних контрибуций: DCO или CLA (Q10).
- Юридическое подтверждение загрузки проприетарных плагинов GPL-хостом (LIC-005).
- Подтвердить лицензии закреплённых версий ASIO SDK и VST3 SDK до их подключения.
