# jdance 0.4.1.1 — окно выбора плагинов по макету

## Установка (Windows 10/11, x64)

Скачайте `jdance-0.4.1.1-windows-x64.msi` и запустите; установка поверх
0.4.1 обновляет программу. Установщик не подписан: Windows SmartScreen
может показать предупреждение «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». Контрольная сумма — в файле `.sha256` рядом с
установщиком.

Формат проекта не менялся (21): проекты 0.4.1 и 0.4.1.1 взаимозаменяемы.

## Исправлено

- **Окно выбора плагинов (F8)** и список Plugins в Browser оформлены по
  борду R5 · Plugins, который в 0.4.1 пропустили: поле поиска в рамке с
  плашкой клавиши, фильтры чипами (All / Instruments / Effects /
  Favorites / формат), заголовки групп, строки 30 px с иконкой типа
  (инструмент — янтарная, эффект — бирюзовая), совпадение с запросом
  янтарным, производитель справа и звезда избранного в конце строки,
  внизу — клавиши и счётчик найденного.
- **Ctrl+D** — добавить выделенный плагин в избранное или убрать из него
  (было только щелчком по звезде).
- В окне Plugins тип плагина в списке Found больше не обрезается до
  «Inst…».
