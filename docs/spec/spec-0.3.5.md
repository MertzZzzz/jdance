# Спецификация 0.3.5: штампы (Stamp) и слайд-ноты в piano roll

2026-11-01 · @Mertz

Две функции piano roll для clean-room реимплементации FL Studio (поверх
0.3.4): **штампы** — одним щелчком ставится аккорд, гамма или
ударный рисунок, и **слайд-ноты** — ноты, которые не звучат сами, а
плавно ведут высоту звучащих нот к своей высоте.

Поведение FL описано по официальному руководству Image-Line
(`html/pianoroll.htm`) — по выдержкам поисковой выдачи: прямое чтение
image-line.com из среды разработки закрыто сетевой политикой, — по
сторонним учебным статьям и по скриншоту меню штампов, присланному
заказчиком (использован только для перечня пунктов; в репозиторий не
добавлен). Ссылки — в конце. Код, ресурсы и бинарники FL не
используются (CR-002). Интервалы аккордов и гамм — общеизвестная теория
музыки; таблицы составлены заново. Где руководство молчит, решение
принято здесь и помечено **[Н]** (решение jdance); неподтверждённое
поведение FL помечено **[?]**.

Приоритеты: **P0** — в релиз, **P1** — по возможности, **P2** — позже.

## Как в FL (по источникам)

**Штамп (Stamp).** Инструмент piano roll, вызываемый из меню
инструментов (правый клик по Draw) [?]. В меню выбирается аккорд или
гамма; щелчок в сетке ставит выбранную фигуру в месте щелчка (высота и
время), с учётом Snap. Пункт «Only one» вверху меню: после одной
постановки инструмент возвращается к одиночной ноте; если его снять,
фигуру можно ставить многократно. Пункт «(none)» (Shift+N) снимает
штамп. Меню разбито на разделы «Melodic — chords» (с подменю Advanced и
пунктом «Automatic chord»), «Melodic — scales», «Percussions» (Fill each
1/2/3/4/8 steps, Flam fast/med/slow, Roll fast/med/slow dynamic/relative)
и «Special» (Slide up). Руководство упоминает режим, в котором щелчок
задаёт верхнюю ноту аккорда; аккорды учитывают Snap и выбранную гамму.

**Слайд-ноты.** Переключатель Slide: пока он включён, новые ноты
становятся слайд-нотами. Слайд-нота заставляет звучащие одновременно с ней
ноты (выше или ниже) скользить к её высоте; к концу слайд-ноты они
достигают её высоты, то есть длина слайд-ноты — время скольжения. Сама по
себе, без перекрытия обычной ноты, слайд-нота не звучит. При аккорде
высоты слайд-ноты достигает верхняя нота. Слайд действует только на ноты
того же цвета (цвет привязан к MIDI-каналу). Работает только с
собственными инструментами FL, не с VST. Отдельно существует флаг
portamento (скольжение от предыдущей ноты) — в этот релиз не входит.

| 1.2 | Меню: флажок **Only one** (по умолчанию включён), **(none) · Shift+N**, **Automatic chord**, затем разделы с заголовками «Melodic — chords» (подменю **Advanced**), «Melodic — scales» (подменю **Scales**: 32 пункта не помещаются в одну колонку меню **[Н]**), «Percussions», «Special» | P0 |

## 4. Ударные штампы

Все ударные штампы ставят ноты на **опорной клавише** в пределах длины
фигуры `L` (§1.5–1.6). `S` — один шаг (1/16, 240 тиков). Источник даёт
только названия пунктов; значения — решения jdance **[Н]**.

| Штамп | Что ставит |
|---|---|
| Fill each N steps (N = 1, 2, 3, 4, 8) | Ноты каждые `N·S` от начала, пока начало внутри `L`; длина каждой — `min(S, остаток L)`; минимум одна нота |
| Flam fast / med / slow | Основная нота длины `L` и форшлаг длиной `d` перед ней (`d` = S/8, S/4, S/2), velocity форшлага — 60 % основной. Если перед началом нет места (`начало < d`), основная нота сдвигается на `d` вправо, форшлаг встаёт на место щелчка |
| Roll fast / med / slow | Повторы через `r` = S/4, S/2, S (длина каждой — `r`, последняя обрезается по `L`) |
| — dynamic | velocity растёт линейно от 35 % до 100 % velocity новых нот (крещендо) |
| — relative | velocity всех повторов одинакова — velocity новых нот |

| № | Требование | Приоритет |
|---|---|---|
| 4.1 | Ударные штампы не зависят от Snap внутри фигуры (сетка фигуры — свои интервалы), Snap действует только на точку щелчка и длину | P0 |
| 4.2 | Ноты, которые не помещаются в лимит строки, отбрасываются | P0 |

## 5. Особый штамп Slide up

Обычная нота на опорной клавише длины `L` и слайд-нота на октаву выше,
занимающая вторую половину `L` (начало `L/2`, длина `L − L/2`): нота
звучит, а во второй половине поднимается на октаву **[Н]**. Если октава
выше выходит за 127 — слайд-нота на 127.

## 8. Воспроизведение слайдов (сэмплер)

Группа нот, на которую действует слайд, — ноты **того же канала того же
паттерна**. Цветов нот (MIDI-каналов) в jdance нет, поэтому правило FL
«того же цвета» сводится к «того же канала» **[Н]**.

| № | Требование | Приоритет |
|---|---|---|
| 8.1 | Слайд-нота не создаёт голос и не звучит | P0 |
| 8.2 | В начале слайд-ноты голоса её канала, звучащие от нот секвенсора (не в фазе затухания, не живые ноты с клавиатуры), начинают скольжение | P0 |
| 8.3 | Интервал скольжения: `ключ слайда − наибольший текущий ключ среди этих голосов`; все голоса сдвигаются на этот интервал (верхний приходит к высоте слайда, аккорд сохраняет форму) | P0 |
| 8.4 | Скольжение — экспоненциальное по частоте (линейное в полутонах) на длину слайд-ноты; к её концу голос точно на новой высоте и остаётся на ней | P0 |
| 8.5 | Слайды подряд складываются: следующий слайд считает от уже достигнутой (или целевой) высоты | P0 |
| 8.6 | Если в момент слайда голосов нет — слайд ничего не делает | P0 |
| 8.7 | Слайд и нота в одном тике: нота стартует раньше, слайд действует на неё | P0 |
| 8.8 | Длительность звучания исходной ноты не меняется (гейт — по её собственной длине) | P0 |
| 8.9 | Офлайн-рендер (`jdance render`, экспорт) звучит так же — тот же процессор | P0 |
| 8.10 | Без аллокаций в аудиопотоке (RT-001) | P0 |

## 9. Слайды на VST3

FL поддерживает слайды только в своих инструментах. В 0.3.5 на каналах
VST3 слайд-ноты **не отправляются** плагину (не звучат и не ведут
высоту). Позже (P2): VST3 Note Expression «Tuning» для плагинов, которые
его поддерживают, или pitch bend с заданным диапазоном.

## Критерии приёмки

- Тесты `commands`: интервалы каждого аккорда и гаммы, автоматический
  аккорд в до мажоре и ля миноре, ударные штампы (число нот, позиции,
  velocity), Slide up, отсечение по 127 и лимиту.
- Тест `dsp`: голос со скольжением на октаву за N сэмплов доходит до
  двойной скорости и остаётся на ней.
- Тест `engine`: нота + слайд-нота на октаву выше — частота звука в конце
  слайда вдвое выше начальной; одна слайд-нота — тишина; заглушённая
  слайд-нота — высота не меняется.
- Тест `persistence`: флаг slide сохраняется и читается; файл v18
  открывается.
- Тест `ui`: штамп Major щелчком ставит три ноты, Only one сбрасывает
  штамп; переключатель Slide ставит слайд-ноту.
